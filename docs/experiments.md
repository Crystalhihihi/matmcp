# 实验与事故记录（matmcp）

格式：每条 = 事实 → 根因 → 立下的规矩。只记有证据的。

## E0 · P0/P1 环境与会话验证（2026-08-12，通过）

- WSL2 Ubuntu + conda-forge 一把装好 GPAW 25.7（PAW 势随 `gpaw-data` 包自动装）。
- P0 门：H2 键长 0.756 Å（exp 0.74）；Si 能带图教科书形状。
- P1 门：MoS2 单层全链 gap=1.678 eV，K–K 直接（MP 参考 1.66）。
- MCP 协议冒烟通过；`.kimi-code/mcp.json` 配好（wsl 启动，工具超时 30 min）。
- **坑 1**：Git Bash 会把 `/mnt/d/...` 参数改写成 `C:/Program Files/Git/mnt/...`。
  规矩：调 wsl.exe 时前缀 `MSYS_NO_PATHCONV=1`。
- **坑 2**：`bash -lc` 不一定执行 `.bashrc` 尾部的 export（交互守卫提前 return）。
  规矩：环境激活全部显式写在启动命令里，不依赖 rc 文件。

## E1 · "间接带隙"误读事件（2026-08-12，验收器的存在意义）

- 事实：新会话 agent 全链算出正确数字（gap 1.678 eV），但报告写"价带顶在 Γ 附近，
  呈间接带隙"。GPAW 输出 `bands_scf.txt` 里白纸黑字 `k=[0.33,0.33,0] → [0.33,0.33,0]`（K→K 直接）。
- 根因：agent 目测 png 而非读输出文件；把体材料 2H-MoS2 的知识错套到单层。
- **规矩 1：结论必须有机器出处。** VBM/CBM 位置、直接/间接属性由本征值数值导出进
  summary.json，agent 只许引用。已在 `calc_band_dos` 落地。
- 教训的推广：报告里的每个物理量都要能指认到某个 artifact 文件的某一行。

## E2 · 收敛门放行错误带隙（2026-08-12，P2 首跑"通过"但结果错）

- 事实：垃圾参数（ecut=200, kd=3）被拦截→自动调参到 kd=15（5×5×1）→最终
  gap=2.019 eV "indirect"，verdict=pass_with_warnings，测试 assert 全过。
- 根因（三层，逐层剥）：
  1. 表面层：`auto_kpts` 不懂六方对称性，5×5×1 采不到 K=(1/3,1/3,0)。
  2. 中间层：修成"n%3==0"后**仍错**——k 扫描实测振荡：3×3→1.638、6×6→1.965、
     9×9→1.676、12×12→1.759 eV。**奇数倍数对、偶数倍数错**：GPAW 默认
     Monkhorst-Pack 对偶数 n 网格有偏移，6 和 12 照样采不到 K。
     终修：`_gpaw` 强制 `gamma=True`（Γ 心网格），n%3==0 规则此时才成立。
  3. 判据层：**能量收敛 ≠ 带隙收敛**。实测 ecut 扫描 ΔE=74.6→12.9→3.53→3.42
     meV/atom（绝对能量渐近收敛，800 eV 内到不了 2 meV/atom），而带隙在 400 eV
     已稳定到 0.4 meV。能量门定 5 meV/atom，带隙门 0.02 eV，双判据缺一不可。
- 次生 bug：ecut 扫到 600 封顶未收敛时，重试逻辑对天花板空转 2 次。
  修复：撞天花板带根因记录退出，不再空转；verify_run 新增 convergence_gate 检查行。
- **规矩 2：测试通过 ≠ 结果正确。裁决看物理量本身，不看退出码。**
- **规矩 3：对称性知识（K 点落在哪类网格、Γ 心与否）属于确定性代码，
  不属于 agent 的记忆。**
- **规矩 4：收敛判据要盯你报告的那个物理量，不是只盯能量。**

## E3 · MP_API_KEY 401 集体崩溃（2026-08-12，四个子代理首轮全挂）

- 事实：四个回归子代理首轮全部 `MPRestError 401: No API key found`，秒崩。
- 根因：`load_secrets()` 只挂在 MCP server 入口；`tools/regression_one.py` 直调
  `verify.run_verified_workflow` 的 CLI 路径从不调用它。key 文件好好躺在
  `~/.config/matmcp/env`，没人读。
- 修复：`load_secrets()` 下沉到 `workflows.fetch_structure` 入口（真正的消费者处），
  server 路径与 CLI 路径行为一致。
- **规矩 5：秘密/配置的加载点放在消费它的函数里，不放调用链顶端。**

## E4 · LiCoO2 判 fail —— 验收器在正确工作（2026-08-12）

- 事实：mp-22526 全链跑完，PBE gap=1.146 eV vs MP 参考 0.662 eV，|Δ|=0.484 →
  band_gap_vs_mp **fail**；convergence_gate warn（强关联体系 k 点难收敛）。
- 判定：**这不是 bug，是验收器抓到了真实的方法学局限**——LiCoO2 是 Co 3d 强关联
  体系，PBE 无 +U 无磁性设置本来就不可信；MP 参考值本身也是 PBE 级别。系统该 fail。
- 规矩 6（强化）：**不为让测试变绿而放宽阈值。** fail 带根因就是正确答案。
  demo 叙事里这是一个卖点：系统会拒绝，不装。

## E5 · 子代理后台任务被回收（2026-08-12，流程事故）

- 事实：三个子代理在各自 turn 内挂后台计算任务后收尾"completed"，turn 结束后台
  进程被一并回收，任务句柄成孤儿，主线 TaskList 不可见。
- **规矩 6b：长耗时计算的启动权在主线（主线 background task 有完成通知）；
  子代理只做有界任务（turn 内能闭环的分析/改造/评审）。**

## E6 · 真空轴检测误判风险（2026-08-12，预防性修复）

- 事实：旧规则"晶胞长度 >12 Å = 真空方向"。审查发现对层状**体材料**会误判
  （如 LiCoO2 六方设定 c≈14 Å 是真实周期方向）。实测 MP 返回的是菱方原胞
  （三轴均 4.91 Å），本次未误伤，但规则本身是定时炸弹。
- 修复：`_vacuum_axes` 改用原子跨度判据（轴向上最大原子间隙 >8 Å 才算真空）。
- **规矩 7：几何/对称性判断要看原子实际占据，不看晶胞参数表面值。**

## E7 · 收敛判据对准产品物理量（2026-08-12，TiO2 触发）

- 事实：金红石 TiO2 的 ecut 扫描 ΔE=3519→966→235→67 meV/atom（Ti PAW 含半芯态，
  绝对能量 800 eV 也压不到 5），但 Δgap=0.28→0.047→0.023→**0.0003**——
  带隙在 600 eV 早已收死。k 点轴则干净双收敛。旧政策"两轴同一能量门"对 TiO2
  只能给 warn。
- 决策：**截断能轴主判据改为带隙稳定度（Δgap<0.02 eV），能量留 100 meV/atom
  兜底防病态；k 点轴维持双判据（ΔE<5 meV/atom 且 Δgap<0.02 eV）。**
- 依据：跨截断能比较绝对能量无物理意义（能量差只在同截断能下可比较）；
  我们报告的产品是带隙，判据必须对准产品。这不是放宽阈值，是修正判据的指向。
- **规矩 8：收敛判据的严格度要和泛函自身系统性误差（PBE 低估带隙 ~40%）放在
  同一把尺上量；超过它就是自我感动。**

## E8 · 敌意审查与修复（2026-08-12 晚，子代理 hostlie review）

审查结论"是资产但带引信"。九条发现及处置（S 编号对应审查报告）：

- **S1 收敛门是装饰品**：`run_verified_workflow` 旧版无论收敛与否都无条件出图出带隙。
  已修：门不开（撞天花板/弛豫未收敛/SCF 崩溃）→ 状态 `rejected_unconverged`，
  **不产出任何最终结果**；verify fail → `rejected_by_verifier`，产物标注"仅供取证禁止引用"。
  SCF 崩溃现纳入 try/except 带根因退出（原来炸穿整个工作流）。
- **S2 金属崩溃**：`vbm=None` 时 `.get('label')` 抛 AttributeError，数小时计算后崩在
  验收器。已修（metallic → info 行），合成用例验证通过。
- **S3/S4/S5 宣称超发**："≤0.1 eV"（实际 0.104）、"Γ→X"（对裸坐标的人工解读，自违立法）、
  verdict best-of-N、PBE-vs-PBE 循环论证未声明、内置 MoS2 参考值是硬编码常数。
  已在 README 增"坦白三条"一节逐一写明边界；能力声明同步修正。
- **S6 "引擎可换"超发**：无抽象层，GPAW 私有 API 深耦合。README 架构图改为
  "当前单引擎 GPAW，QE 适配为下一步（工作流层需重写）"。

  未修（记录在案）：弛豫不含晶胞（MP 结构本近平衡，Si/GaAs/TiO2 的 relax 是空转验证）、
  收敛扫描无缓存重跑浪费、drift 检查无最小镜像约定、零单元测试零 CI。

  代表性证据（关键 json + png）进 `evidence/` 目录提交，原始大文件仍留本地。
- **S9 VASPilot 话术自杀**：demo 答案原稿"它只检查跑完没有"——实际上 VASPilot 有

- **规矩 9：自我拷打要进流程。** 每个里程碑完成后跑一次敌意审查子代理；
  宣称的每个数字都要能指认到 artifact 原件，包括 README 里的。

## E11 · QE 偶数网格又踩 K 点（2026-08-12 晚，E2 的跨引擎重演）

- 事实：QE 腿首次对比被判 `rejected_unconverged`（门真的拦了，S1 修复实证）。
  查收敛扫描：k 序列 3×3→1.6705、6×6→1.9871、9×9→1.7028、12×12→1.781、
  15×15→1.703——**3/9/15 对、6/12 错**，和 E2 的 GPAW 振荡同构。
- 根因：ASE `kpts2sizeandoffsets` 对 gamma=True 的偶数 n 轴给半步偏移
  （`s % 2 != bool(gamma)` → offset=0.5/s），6/12 网格照样采不到 K；
  GPAW 的 gamma=True 是全奇偶 Γ 心。**同一 API 参数，两引擎语义不同。**
  子代理"同一物理网格"的判断只验证了奇数轴。
- 修复：引擎接口新增 `realize_kpts()`——QE 侧偶数一律向上取奇
  （3 的倍数取到下一个奇倍数 6→9、12→15，保 K），GPAW 恒等；
  调用方（workflows/verify 扫描）一律用 realize 后的网格记账，
  记录参数=执行参数。
- **规矩 13：跨引擎移植时，"同名参数同语义"必须用数据验证，不能靠文档推断。
  对称性规则的验证集必须同时含奇偶网格。**

## E12 · 公开仓库卫生事故（2026-08-12 晚，用户发现）

- 事实：matmcp 首次推送把求职私货（面试剧本/目标公司调研/500 字提议草稿/冲刺计划）
  一并提交进公开仓库。面试官顺简历摸进来会先读到面试剧本。
- 处置：filter-repo 从全历史抹除（demo-script/capability-statement/plans/research），
  本地留档于 docs-private/（已 gitignore）；同晚对全部公开仓库做了一轮审计并修复
  （仓库描述口吻、死链、粗口引述、临时文件、路径硬编码、topics 补全）。
- **规矩 14：公开前三检——①敏感内容（密钥/个人信息/版权物）②求职私货
  （策略/剧本/评价真实公司个人）③门面（README/描述/topics/LICENSE）。
  仓库是给面试官看的作品本身，求职话术永远不进仓库。**
- 规矩 15（审计员发现推广）：**私人工作区与公众门面的边界意识**——交接文档、
  本地路径、额度私话这类"后台"内容，默认不进公开仓库。
